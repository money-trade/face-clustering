# face-clustering

เปิดกล้องแล้วบอกว่าหน้าที่เห็น **คล้ายเพื่อนคนไหนในห้อง** ด้วย **KNN (k-Nearest Neighbors)**
เทียบกับรูปเพื่อนในโฟลเดอร์ `ML_Data_Morning/` ใช้แค่ OpenCV กับ NumPy

## ไฟล์ในโปรเจค

| ไฟล์ | หน้าที่ |
|---|---|
| `FaceTrain_2.py` | อ่านรูปใน `ML_Data_Morning/` ตัดเฉพาะหน้า แล้วบันทึกเป็น `knn_model.npz` |
| `FaceClustering.py` | เปิดกล้อง หาหน้าในภาพ แล้วหาเพื่อนที่หน้าคล้ายที่สุดด้วย KNN |
| `face_utils.py` | หาหน้า (Haar Cascade) ตัด และปรับแสง ใช้ร่วมกันทั้งสองไฟล์ ให้เทียบกันได้ |
| `ML_Data_Morning/` | รูปเพื่อนในห้อง 32 ไฟล์ คนละ 1 รูป |
| `knn_model.npz` | สร้างเองตอนรัน `FaceTrain_2.py` (ไม่เก็บใน git) |

## ติดตั้ง

```bash
pip install -r requirements.txt
```

> ต้องใช้ **OpenCV เวอร์ชัน 4** (`opencv-python<5`) เพราะ OpenCV 5.0 ถอด `cv2.CascadeClassifier` (ตัวหาหน้า) ออกแล้ว
> ถ้าติดตั้ง 5.0 ไปแล้ว ให้รัน `pip install "opencv-python<5"`

## วิธีใช้

**1. เทรน** (ทำครั้งแรก และทุกครั้งที่เพิ่ม/เปลี่ยนรูป)

```bash
python FaceTrain_2.py
```

**2. เปิดกล้อง**

```bash
python FaceClustering.py
```

- มองกล้องตรง ๆ ระบบหาหน้าเองทุกเฟรม ไม่ต้องจัดหน้าให้ตรงกรอบ และหาได้หลายคนพร้อมกัน
- กรอบ **เขียว** = คล้ายเพื่อนที่แสดงชื่อ พร้อม % ความคล้าย, กรอบ **แดง** `Unknown` = ไม่คล้ายใครชัดเจน
- บรรทัดล่าง `Similar to: n person(s)` = จำนวนเพื่อนที่ผ่านเกณฑ์ (จาก 5 คนที่ใกล้สุด)
- กด `q` เพื่อออก

ทั้งสองไฟล์รันจากโฟลเดอร์ไหนก็ได้ (หาไฟล์จากโฟลเดอร์ของสคริปต์เอง)

### ตั้งชื่อไฟล์รูป

`รหัส_ชื่อเล่น.jpg` เช่น `6752300046_Taer.jpg`

- ใช้ `_` ช่องว่าง หรือ `-` คั่นก็ได้ และนามสกุลซ้อน (`.jpg.jpg`) ก็อ่านได้
- รองรับ .jpg .jpeg .png ส่วนรูปจาก iPhone (HEIF/HEIC) ต้องแปลงเป็น .jpg จริงก่อน
  ถ้าแค่เปลี่ยนชื่อเป็น .jpg ระบบจะแจ้งว่าเป็นไฟล์ HEIF แล้วข้าม
- ชื่อเล่นซ้ำกัน ระบบต่อท้ายด้วยเลข 4 ตัวท้ายของรหัสให้ เช่น `First(0607)`, `First(1115)`
- ถ้ารหัสไม่ใช่ตัวเลข 10 หลัก จะมีคำเตือนให้ตรวจชื่อไฟล์

## หลักการทำงาน

1. **ตัดหน้า** (`face_utils.py`): รูปในโฟลเดอร์มีขนาดตั้งแต่ 140×180 ถึง 3159×3877 พิกเซล
   จึงหาหน้าด้วย Haar Cascade ตัดช่วงหน้าผากถึงคาง แก้มถึงแก้ม ย่อเป็นขาวดำ 140×180
   แล้วปรับแสง (`equalizeHist`) ได้เวกเตอร์ 25,200 ค่าต่อคน ภาพจากกล้องก็ผ่านขั้นตอนเดียวกัน
2. **ระยะห่าง**: ค่าพิกเซลต่างกันเฉลี่ย (RMS, 0–255) ระหว่างหน้าในกล้องกับเพื่อนทุกคน
3. **KNN**: เลือก 5 คนที่ใกล้ที่สุด แล้วเก็บเฉพาะคนที่ระยะไม่เกิน threshold
4. **threshold ตั้งจากข้อมูลจริง**: ตอนเปิดโปรแกรมวัดระยะระหว่างเพื่อนต่างคนกันทุกคู่ในห้อง
   แล้วใช้ค่าที่ percentile 10 แปลว่า "คล้าย" = ใกล้กว่า 90% ของคู่เพื่อนในห้อง
5. **% ความคล้าย** = 1 − (ระยะของคนที่ใกล้สุด ÷ ระยะกลางของคู่เพื่อนในห้อง)

## ตั้งค่า (ด้านบนของ `FaceClustering.py`)

| ค่า | ปัจจุบัน | ความหมาย |
|---|---|---|
| `K` | `5` | ดูเพื่อนบ้านใกล้ที่สุดกี่คน |
| `THRESHOLD_PCT` | `10` | เกณฑ์ "คล้าย" ยิ่งน้อยยิ่งเข้ม (5 = ใกล้กว่า 95% ของคู่เพื่อน) |
